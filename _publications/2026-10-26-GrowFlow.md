## Abstract

Smart, connected applications increasingly require low-latency inference from models that adapt as physical conditions evolve. However, high-fidelity simulation and model generation require substantial remote computation, making them unsuitable for the IoT inference critical path. We present GROWFLOW, an adaptive
IoT system that decouples low-latency edge inference from computationally intensive model generation using an asynchronous online/offline architecture. The online path serves inference using the latest surrogate model, while the offline path continuously executes high-fidelity simulation and model training on remote HPC resources. We evaluate GROWFLOW in a field-scale digital agriculture deployment using CFD-generated wind fields and Principal Component Regression (PC-R). GROWFLOW refreshes models in approximately 31 minutes and provides sub-second inference across 12,920 spatial locations, over 1000× faster than direct CFD simulation. Under continuous operation, model staleness remains approximately 0.5–1 h with prediction error comparable to sensor measurement uncertainty; without refresh, error increases substantially. These results demonstrate how asynchronous model updating can support responsive, adaptive IoT inference despite disparate inference and model-generation time scales.
